# 📈 Stock Market Data Analysis Using Python

## 📌 Project Overview
This project focuses on analyzing stock market data using Python to understand price movements and identify potential trading insights. Various technical indicators were calculated and analyzed to study market trends and support decision-making.

The analysis is performed on historical stock price data and includes data preprocessing, indicator calculation, and result interpretation.

## 🛠️ Tools & Technologies
- Python
- Pandas
- NumPy
- Jupyter Notebook
- Matplotlib
- Excel

## 📊 Technical Indicators Implemented
- Relative Strength Index (RSI)
- Volume Weighted Average Price (VWAP)
- Fibonacci Retracement Levels
- Pivot Points (Support & Resistance)

## 📈 Analysis Performed
- Data loading and cleaning
- Date-wise filtering of stock data
- Calculation of RSI to identify overbought and oversold conditions
- VWAP computation for price trend analysis
- Fibonacci retracement for trend reversal levels
- Pivot point calculation for intraday support and resistance

## 📂 Project Files
- Jupyter Notebook containing complete analysis
- PDF documentation explaining stock market indicators
- Processed output data exported to Excel

- Improved data analysis and visualization skills
